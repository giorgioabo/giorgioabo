## 📌 Proyecto destacado

### ⚡ [TechDrop](https://techdropproject.netlify.app/) — E-commerce Full Stack

Tienda online de tecnología desarrollada en solitario, de principio a fin: diseño, frontend, backend, base de datos y despliegue.

<p>
  <a href="https://techdropproject.netlify.app/"><img src="https://img.shields.io/badge/🌐_Ver_demo-FF5B1F?style=for-the-badge" alt="Ver demo"></a>
  <a href="https://github.com/giorgioabo/Final-Project-Giorgio"><img src="https://img.shields.io/badge/💻_Código-181717?style=for-the-badge&logo=github&logoColor=white" alt="Código"></a>
</p>

**Lo que incluye:**
- 🛒 Catálogo con búsqueda instantánea, filtros combinables guardados en la URL, comparador de productos y vista rápida.
- 💳 Carrito persistente, cupones de descuento y checkout por pasos con validación de tarjeta (algoritmo de Luhn).
- 🔐 Registro e inicio de sesión con **JWT** y contraseñas cifradas con **bcrypt**; límite de intentos contra fuerza bruta.
- 📊 **Panel de administración** con KPIs, gráfica de ingresos, gestión de productos, pedidos (con reposición de stock al cancelar) y clientes.
- 🖼️ Subida de fotos de producto a un **almacenamiento de objetos S3** privado, servidas con URLs firmadas.
- 🧱 Arquitectura resiliente: si el backend no responde, la tienda sigue funcionando en modo demo.
- ✅ Pruebas automáticas de la API con **pytest**.

**Stack:** React 18 · Vite · React Router · Python · Flask · SQLAlchemy · PostgreSQL (Neon) · JWT · boto3 · Netlify · Render
